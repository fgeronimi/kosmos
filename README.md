# kosmos

Carte des *Pensées* de Marc Aurèle : chaque pensée est un point, placé selon sa proximité de sens avec les autres. Plus un dashboard qui suit le score d'éval de `memento` run après run.

Projet test de [mr-orchestrator](../mr-orchestrator). Le tag `baseline-v0` marque l'état de départ des runs.

```bash
uv sync
uv run pytest
```
